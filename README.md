# AI data analysis workflow: ask an LLM about a CSV without sending the rows

A hands-on workflow for analysing spreadsheet data with a language model while the data stays on your machine. The model sees column names, types and aggregates, writes the pandas code, and explains the result; your computer does the counting. Two ways to run it: a single Python script, or the OpenCode coding agent with project rules.

[How it works](#how-it-works) · [Script quick start](#quick-start-the-script) · [OpenCode setup](#the-agent-way-opencode) · [Questions to try](#questions-to-try) · [Cost](#what-a-question-costs) · [Glossary](#glossary) · [FAQ](#faq)

<sub>Last checked: 2026-10-07 with pandas 3.0.6 and 2.2.3, Python 3.9+ (3.11 tested), and the OpenCode docs at opencode.ai/docs.</sub>

## How it works

| Step | Where it runs | What leaves your machine |
|---|---|---|
| 1. Profile the CSV: types, nulls, ranges, top values | your machine | nothing |
| 2. Ask the model for an `analyze(df)` function | model API | the profile and your question |
| 3. Read the code, then run it | your machine, separate process, API key removed | nothing |
| 4. Ask the model to explain the result | model API | the code and its result table (≤ 50 rows) |

The model is good at turning a question into a correct groupby, pivot or date filter. It is bad at reading 2,400 rows in a prompt and adding them up. Let each side do what it is good at.

## Quick start: the script

```bash
git clone https://github.com/peregrinestrand/ai-data-analysis-workflow
cd ai-data-analysis-workflow
pip install pandas
export OPENAI_API_KEY=your-key
export OPENAI_BASE_URL=https://argolink.io/v1   # default; any OpenAI-compatible endpoint works

python analyze.py data/orders.csv --show-profile                     # exactly what the model will see
python analyze.py data/orders.csv "Which region and channel lost the most revenue from Q2 to Q3?"
python analyze.py data/orders.csv --run-file analysis/001_analysis.py  # after you have read the code
```

The second command saves the model's function to `analysis/001_analysis.py` and prints it. The third runs that exact file and sends its result back for a written answer, with the tokens and dollars used. `--run` does both in one go when you trust the setup.

The default model is GPT-6 Sol on [ArgoLink](https://argolink.io/gh-ai-data-analysis-workflow), one key for every model in the cost table below. Pick another with `--model` and an effort with `--effort low`.

`data/orders.csv` is synthetic: 2,400 orders from January to September 2026, generated by `data/make_sample.py` (seeded, so it is reproducible), with one planted pattern to find.

### What the model sees

`--show-profile` prints the payload. For the sample file, three of its nine columns:

```json
{"name": "order_date", "dtype": "datetime64[us]", "nulls": 0, "distinct": 273, "min": "2026-01-01", "max": "2026-09-30"}
{"name": "region", "dtype": "str", "nulls": 0, "distinct": 4, "top": {"LATAM": 659, "NA": 592, "APAC": 579, "EMEA": 570}}
{"name": "returned", "dtype": "bool", "nulls": 0, "distinct": 2, "true_share": 0.0417}
```

The whole code-writing prompt is about 1,900 characters (roughly 480 tokens). No order ID, date or row appears in it unless you pass `--sample-rows N`.

### A reference answer

[examples/001_q2_vs_q3_by_segment.py](./examples/001_q2_vs_q3_by_segment.py) is a hand-written `analyze(df)` of the shape the script asks for. Run through `--run-file`, it returns:

```json
{"largest_q2_to_q3_revenue_drops": [
  {"region": "APAC",  "channel": "partner", "q2_revenue": 200151.3, "q3_revenue": 52029.6,  "change_pct": -74.0},
  {"region": "NA",    "channel": "web",     "q2_revenue": 264775.3, "q3_revenue": 175994.8, "change_pct": -33.5},
  {"region": "LATAM", "channel": "web",     "q2_revenue": 315088.6, "q3_revenue": 230771.8, "change_pct": -26.8}]}
```

Compare the model's function with it: a correct one finds the APAC partner drop.

### The profile catches loading mistakes before the model does

Our first profile of this file showed `region` with 592 missing values. Nothing was missing: pandas reads the string `NA` as "not available" by default, so every North America order became NaN, and that second row above (NA web, −33.5%) disappeared from every grouped result without an error. `analyze.load()` now treats only empty cells as missing (`keep_default_na=False, na_values=[""]`). Read the profile before you trust any answer.

## The agent way: OpenCode

[OpenCode](https://opencode.ai) is an open-source terminal coding agent. This repo ships the two files it needs:

- [opencode.json](./opencode.json): two providers on the same base URL. `@ai-sdk/openai-compatible` for models whose native API is Chat Completions (`deepseek-v4-pro`, `glm-5.3`), and `@ai-sdk/openai` for GPT-6 Sol on the Responses API, which it needs to call tools while reasoning. The key comes from `{env:OPENAI_API_KEY}`, and `permission` asks before every shell command and edit.
- [AGENTS.md](./AGENTS.md): rules OpenCode loads automatically. Never print data files, learn the data from `--show-profile`, write scripts under `analysis/`, cite the script behind every number.

```bash
curl -fsSL https://opencode.ai/install | bash    # or: npm install -g opencode-ai
cd ai-data-analysis-workflow
export OPENAI_API_KEY=your-key
opencode                                         # then ask: "Which channel grew fastest in Q3? Show the script."
```

Switch models inside OpenCode with `/models` (`gateway/deepseek-v4-pro`, `gateway/glm-5.3`, `gateway-responses/gpt-6-sol`). The agent costs more per question than the script, because every turn re-sends the conversation and the files it has read.

## Questions to try

On `data/orders.csv`, each answerable from the columns in the profile:

| # | Question | What a correct analysis has to get right |
|---|---|---|
| 1 | Which region and channel lost the most revenue from Q2 to Q3? | exclude returns; revenue = units × unit_price |
| 2 | What share of revenue came from each product in Q3? | shares sum to 100% |
| 3 | Is the average discount different by channel? | mean of `discount`, not of prices |
| 4 | Which product has the highest return rate? | rate = returned orders / all orders per product |
| 5 | Show monthly revenue for APAC partner orders. | month buckets from `order_date` |
| 6 | Did average units per order change after June? | compare H1 and Q3 means, state the n |
| 7 | Which five days had the most orders? | count rows, not units |
| 8 | How much revenue did discounts cost us in Q3? | `unit_price` is already discounted: list price = unit_price ÷ (1 − discount) |
| 9 | Are North America and EMEA growing at the same rate? | keeps the `NA` region |
| 10 | Which segments would we flag if any drop over 25% is an alert? | the threshold applied to the same Q2→Q3 table |

## Glossary

| Term | Meaning here |
|---|---|
| Profile | A summary of a table: each column's type, missing count, distinct count, range or most common values. |
| pandas | The Python library for tables (`DataFrame`) used to load and compute. |
| dtype | A column's type in pandas: `int64`, `float64`, `bool`, `str`, `datetime64`. |
| NaN / NA | pandas' marker for a missing value; also what it turns the text `NA` into unless told otherwise. |
| Aggregate | A number computed from many rows: a sum, mean, count or share. |
| Pivot table | A table with one variable down the side, another across the top, and an aggregate in each cell. |
| Token | The unit models read and write and APIs bill; roughly four characters of English. |
| Reasoning effort | How long a model thinks before answering (`low` … `max`); thinking tokens bill as output. |
| OpenAI-compatible endpoint | An API that accepts OpenAI's request format at a base URL such as `https://argolink.io/v1`. |
| Coding agent | A tool (here OpenCode) that lets a model read files, run commands and edit code in a loop. |
| AGENTS.md | A file of project rules an agent reads before it starts. |

## FAQ

**Does any of my data reach the model provider?**
With the script: the profile (column names, types, counts, ranges, up to 8 most common values per low-cardinality column), the generated code, and the result table you ran. Not the rows, unless you pass `--sample-rows`. Top values can still be sensitive (customer names in a low-cardinality column), so read `--show-profile` first.

**Is running the generated code safe?**
`run_code()` runs it in a separate Python process with `OPENAI_API_KEY` removed from the environment, and the prompt forbids file access. That is not a sandbox: read the code before `--run-file`, or run it in a container.

**Why not upload the CSV to a chat app?**
Uploads put every row in front of the model and leave the arithmetic to it. Here the arithmetic is pandas, and the numbers in the answer come from code you can re-run.

**Which model writes the best pandas?**
Compare them on your own questions: generate with two models, run both files, and diff the results against the reference function above.

**Can I use Excel files?**
Convert to CSV, or change `load()` to `pd.read_excel` (needs `openpyxl`); keep the same missing-value rule.
